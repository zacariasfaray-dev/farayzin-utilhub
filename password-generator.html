What makes a password strong?

Length beats cleverness. A random 16-character password with mixed types is vastly harder to crack than a short one with substitutions — and easier to let a generator pick than to invent. For anything important, use 16+ characters.

Randomness must be real. This page uses your browser's crypto-quality random source (crypto.getRandomValues), not a pattern a hacker could reproduce. Avoid personal dates, names and keyboard walks like "qwerty".

One password per site. Reusing a password means one breach opens many doors. Pair these passwords with a password manager and turn on two-factor authentication where it exists.

Password FAQ

Are these passwords sent to a server?

No. Generation happens entirely in your browser using the Web Crypto API. Nothing is transmitted, logged or stored — you can verify by loading the page and disconnecting from the internet.

Which length should I choose?

16 is a solid default for accounts; 20+ for passwords you rarely type, like a Wi-Fi passphrase or encryption key. Longer is always safer when allowed.

Why include symbols?

Symbols expand the character space, which multiplies the number of possible passwords an attacker must try. Use them whenever a site accepts them.
